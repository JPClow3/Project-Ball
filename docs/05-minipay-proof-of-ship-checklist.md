# MiniPay and Proof of Ship Checklist

## MiniPay

- [ ] Auto-connects inside MiniPay without a connect wallet button.
- [ ] Does not use `personal_sign` or `eth_signTypedData`.
- [ ] Does not show raw addresses as primary identity.
- [ ] Supports only USDm, USDC, and USDT in MiniPay flows.
- [ ] Uses user-facing copy: taxa de rede, depositar, sacar, dolar digital.
- [ ] Works at 360x640.
- [ ] Uses SVG or WebP assets.
- [ ] Handles low balance with a MiniPay deposit deeplink.
- [ ] Includes support URL, Terms, Privacy, and clear app ownership.
- [ ] Provides PageSpeed score for production URL.
- [ ] Provides a full network origin manifest.

## Proof of Ship

- [ ] Public GitHub repository.
- [ ] Project registered on Talent App.
- [ ] Contract deployed on Celo mainnet.
- [ ] Contract verified on Celoscan.
- [ ] App built as a MiniPay Mini App.
- [ ] Valid Proof of Humanity credential for the builder profile.
- [ ] Weekly shipping activity visible through commits and deployments.

## Stats

- [ ] DAU and MAU.

- [ ] Transactions by contract method.
- [ ] Unique on-chain users.
- [ ] Volume by stablecoin.
- [ ] Network fees paid.
- [ ] Protocol fees and burn sink volume.
