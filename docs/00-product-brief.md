# Product Brief

Project Ball is a mobile-first football prediction dApp built for Celo Proof of Ship and MiniPay. The product should feel like a fast casual football game: dark glossy visuals, big match cards, simple choices, and immediate feedback after a transaction.

## Product DNA

- Zero friction: users should not need to understand gas, raw hashes, or wallet internals.
- MiniPay-first: auto-connect inside MiniPay, no arbitrary message signing, and stablecoin-only flows.
- Fast feedback: every bet moves from pending to registered without a full page refresh.
- Retention through rhythm: daily match pools first, longer-term tournament markets later.

## MVP Goal

Ship a public, open-source app that is eligible for Celo Proof of Ship scoring:

- MiniPay-compatible web app.
- Smart contract deployed on Celo mainnet.
- Public stats page for web and on-chain traction.
- Legal, support, and network manifest readiness.
