# Naming Conventions

## Product Language

- Product name: Jonakinho.
- UI language: PT-BR.
- Use: palpite, dolar digital, taxa de rede, depositar, sacar.
- Avoid in user-facing copy: gas, onramp, offramp, crypto, hash as primary feedback, wallet address as identity.

## Code Terms

- `Match`: scheduled football match.
- `Pool`: stake bucket for one match.
- `Outcome`: home win, draw, away win.
- `Pick`: one user's selected outcome.
- `Stake`: amount paid for a pick.
- `NormalizedAmount`: 18-decimal USD accounting amount.
- `Claim`: payout action after resolution.

## Package Names

- `@jonakinho/web`
- `@jonakinho/contracts`
- `@jonakinho/shared`
